# 🚀 AI Prompt Improver - Полное руководство по настройке

## 📋 Обзор проекта

AI Prompt Improver - это браузерное расширение для Chrome, которое предоставляет:

- ✨ **Анализ изображений** - drag & drop загрузка изображений с генерацией промптов
- 📝 **Улучшение текстовых промптов** - с поддержкой разных типов (Civitai, Universal, Textual)
- ⭐ **Избранное с локальным хранением** - работает без авторизации
- 📊 **История** - отслеживание всех операций
- 🔄 **Синхронизация через Google OAuth** - для сохранения данных в облаке

## 🛠 Технологический стек

- **Frontend**: React 18 + TypeScript + Vite
- **Стилизация**: Tailwind CSS
- **Расширение**: Chrome Extension Manifest V3
- **AI интеграция**: HuggingFace, OpenRouter, Local Analysis
- **Хранение**: LocalStorage (без авторизации) + Chrome Storage API

## 🔧 Быстрая установка

### 1. Клонирование и установка

```bash
git clone <repository-url>
cd ai-prompt-improver
npm install
```

### 2. Сборка расширения

```bash
npm run build:extension
```

### 3. Установка в Chrome

1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика"
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку `dist/`

## 🤖 Настройка AI сервисов

### 🔥 Бесплатные модели для анализа изображений

#### 1. HuggingFace (Рекомендуется)

**Получение API ключа:**
1. Регистрируйтесь на [huggingface.co](https://huggingface.co)
2. Перейдите в Settings → Access Tokens
3. Создайте новый токен с правами `read`

**Доступные модели:**
- `Salesforce/blip-image-captioning-large` - анализ изображений (бесплатно)
- `microsoft/DialoGPT-large` - генерация промптов (бесплатно)
- `mistralai/Mixtral-8x7B-Instruct-v0.1` - улучшение промптов

**Лимиты:** ~1000 запросов/день бесплатно

#### 2. OpenRouter

**Получение API ключа:**
1. Регистрируйтесь на [openrouter.ai](https://openrouter.ai)
2. Получите бесплатный API ключ
3. $5 бесплатных кредитов при регистрации

**Бесплатные модели:**
- `microsoft/kosmos-2` - vision анализ (бесплатно)
- `microsoft/wizardlm-2-8x22b` - улучшение промптов
- `meta-llama/llama-3.1-8b-instruct` - генерация текста

**Лимиты:** $5 бесплатных кредитов, затем pay-per-use

#### 3. Резервные методы

- **Локальный анализ** - базовый анализ размеров и пропорций изображения
- **Шаблонная генерация** - промпты на основе ключевых слов

### ⚙️ Настройка API ключей

#### В настройках расширения:

1. Откройте расширение
2. Перейдите на вкладку "Настройки"
3. Введите API ключи:
   - HuggingFace API Key
   - OpenRouter API Key

#### В localStorage (для разработки):

```javascript
// В консоли браузера
localStorage.setItem('huggingface_api_key', 'your_hf_token_here');
localStorage.setItem('openrouter_api_key', 'your_openrouter_key_here');
```

## 🚀 Использование

### 1. Анализ изображений

1. Перейдите на вкладку "Анализ изображений"
2. Перетащите изображение или нажмите "Upload Image"
3. Нажмите "Analyze Image"
4. Выберите формат промпта:
   - **General** - естественное описание
   - **Flux** - оптимизированный для Flux моделей
   - **Stable Diffusion** - с техническими параметрами

### 2. Работа с избранным

- ❤️ **Добавление** - нажмите "Favorite" у любого промпта
- 🔍 **Поиск** - используйте строку поиска в избранном
- 🏷️ **Теги** - фильтруйте по тегам и категориям
- 💾 **Локальное хранение** - работает без интернета

### 3. Google OAuth синхронизация

1. Нажмите "Login with Google" в профиле
2. Разрешите доступ расширению
3. Данные автоматически синхронизируются

## 🔒 Безопасность и приватность

### Локальное хранение
- Все данные без авторизации хранятся локально в браузере
- API ключи никогда не передаются третьим лицам
- Изображения обрабатываются через безопасные HTTPS соединения

### Разрешения расширения
```json
{
  "permissions": [
    "storage",           // Локальное хранение
    "activeTab"          // Доступ к активной вкладке
  ]
}
```

## ⚡ Производительность

### Оптимизации
- Сжатие изображений перед отправкой
- Кэширование результатов анализа
- Ленивая загрузка компонентов
- Минификация CSS/JS

### Лимиты
- Размер изображения: до 4MB
- История: до 200 элементов (локально)
- Избранное: до 100 элементов (локально)
- Анализы изображений: до 50 элементов

## 🔄 Обновление расширения

### В режиме разработки:
1. Внесите изменения в код
2. Выполните `npm run build:extension`
3. Перезагрузите расширение на странице `chrome://extensions/`

### Для продакшена:
1. Обновите версию в `manifest.json`
2. Создайте `.zip` архив папки `dist/`
3. Загрузите в Chrome Web Store
