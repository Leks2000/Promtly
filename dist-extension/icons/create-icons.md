# Icon Creation Instructions

Create the following PNG icons for the Chrome extension:

- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels  
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

The icons should feature:
- A modern, clean design with rounded corners
- Primary color: #3b82f6 (blue-500)
- Icon style: A stylized "AI" or sparkle/lightning symbol
- Background: Gradient or solid color with subtle shadows

For development purposes, you can use placeholder icons or create simple ones using any design tool.
